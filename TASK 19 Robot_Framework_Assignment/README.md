# Robot Framework Login Automation Assignment

## Objective
This project automates the login functionality of:
https://robotsparebinindustries.com/

## Technologies Used
- Robot Framework
- SeleniumLibrary
- Python
- Chrome Browser

## Installation

pip install robotframework
pip install robotframework-seleniumlibrary
pip install webdriver-manager

## Run Command

robot login_test.robot

## Expected Result
- Browser opens
- Login successful
- Dashboard verified
- Logout completed
- Browser closed

## Generated Reports
- report.html
- log.html
- output.xml

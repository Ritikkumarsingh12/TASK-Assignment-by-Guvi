# Task 16 - Selenium Automation Project

## Objective
This project automates the World Population Clock website using:
- Python Selenium
- Page Object Model (POM)
- Explicit Wait
- Expected Conditions
- Pytest
- XPath locators only

## Website Used
https://www.theworldcounts.com/challenges/planet-earth/state-of-the-planet/world-population-clock-live

## Features
- Opens the website automatically
- Extracts live population count
- Displays population count continuously in terminal
- Stops when user presses CTRL + C
- Uses proper comments and code hygiene

## Required Libraries
Install required libraries using:

pip install selenium pytest pytest-html webdriver-manager

## Run Command
pytest -s task16_population_counter.py --html=report.html
